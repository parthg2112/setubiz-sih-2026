# SetuBiz

AI-Driven Hyper-Local Business Advisory & Financial Structuring Assistant for Rural Micro-Entrepreneurs — **SIH 2026, Problem Statement SIH26091** (Ministry of Social Justice & Empowerment).

**Master plan:** [`PLAN.md`](./PLAN.md) — architecture, scheme research (NSFDC Logic A/B mapping), model specs, data plan, timeline to the Sep-20 idea gate, and demo/judge strategy.

> Core rule: ML only where data is uncertain (competitor density, local demand). Every financial calculation and eligibility decision is deterministic code. The language model explains — it never decides.
